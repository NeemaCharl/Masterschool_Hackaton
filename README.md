# ChronoGuesser — Masterschool Hackathon

ChronoGuesser is a fun, interactive history game where you test your knowledge of world events and famous figures. 
Your challenge: guess the correct Wikipedia article from a redacted summary—with the option to request AI-powered hints! 
Compete solo or against friends for top scores on the leaderboard.

## Features

- **Single-player rounds**: Play 3 rounds per game, each featuring a new historical article.
- **Redacted Wikipedia summaries**: Key names blanked out for extra challenge—can you recognize the event or person?
- **AI-generated hints**: Stuck? Ask for up to 2 clever hints per round, generated by OpenAI GPT-5-nano.
- **Scoring system**: Correct answers and fewer hints earn higher points. See the rules for scoring breakdown.
- **Leaderboard**: Your results are saved in `scoreboard.json`—compare your score against other players!

## How to Play

1. **Launch the game**: Run one of the main game scripts, e.g.  
   ```bash
   python final ChronoGuesser update.py
   # or
   python ChronoGuesser_1.0.py
   ```
2. **Instructions & Rules**: The game starts with clear in-terminal instructions and rules.
3. **Rounds**: Each round presents a redacted summary. Enter your guesses (up to 3 attempts per round), or type `hint` for AI help.
4. **Scoring**:  
   - Correct on first try: **1000 pts**
   - Each wrong guess: **-200 pts**
   - Each hint used: **-100 pts**
   - If you fail: **0 pts**
5. **Leaderboard**: After 3 rounds, your score is added to the global leaderboard.

## Example

```
🔎 Round 1
Redacted summary:

_____ was a Polish and naturalised-French physicist and chemist who conducted pioneering research on radioactivity.

Your guess (or 'hint'):
> Marie Curie
✅ Correct! Well done.
```
Or, if you need help:
```
Your guess (or 'hint'):
> hint
💡 Hint 1:
Discovered two elements and won two Nobel Prizes in different sciences.
```

## Requirements

- Python 3.8+
- [wikipedia](https://pypi.org/project/wikipedia/)
- [openai](https://pypi.org/project/openai/)
- (optional) An OpenAI API key for hint generation (`OPENAI_API_KEY` as an environment variable)

```bash
pip install wikipedia openai
```

## Configuration

- Ensure `OPENAI_API_KEY` is set in your environment for hints.  
  Example:
  ```bash
  export OPENAI_API_KEY="your_openai_api_key"
  ```
- Edit `list_of_articles.py` to add or update the set of historical events and people.
- Scoreboard is stored in `scoreboard.json` (automatically created).
